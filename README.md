# LaunchBlast Distribution App

> **Retired Venture experiment — historical reference only.**

This repository contains a Flask prototype for turning a product launch brief into distribution submissions.

## What is implemented

- Product-name, URL, tagline, and description intake
- Dev.to article generation and submission integration
- Hacker News submission integration
- SQLite tracking of per-channel and overall status
- Basic HTML interface and deployment configuration

## Status

Development stopped on July 10, 2026. The application is not maintained or production-ready, and external publishing requires credentials and platform-compatible configuration.

The repository name `launchblast-product-name` is a historical placeholder. A clearer name would be `launchblast-distribution-app`.

Created as part of the archived Venture product-experiment portfolio.
